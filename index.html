The Great Cheese Escape

A 3D mobile game for Android that I built in Unity 6 with C#. It's set in a house environment, uses Unity's AI Navigation (NavMesh) system for character movement, touch input through the Input System, and the Universal Render Pipeline for mobile-friendly 3D graphics. It's compiled with IL2CPP for 64-bit Android phones.
